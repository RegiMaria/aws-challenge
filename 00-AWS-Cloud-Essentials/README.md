# ☁️ 00 - Cloud Essentials - Knowledge Badge Readiness Path

</div>

Este repositório documenta minha jornada para conquistar o [AWS Cloud Essentials Knowledge Badge](https://skillbuilder.aws/learning-plan/XKS3J4FAS7/cloud-essentials--knowledge-badge-readiness-path--includes-labs/Y4YASRJEVX), disponível no AWS Skill Builder.

Esta é a **trilha base (`00_`)** do meu plano de estudos AWS: antes de entrar nas trilhas mais técnicas e específicas

(Security, Compute, Object Storage...), essa trilha dá o panorama geral da nuvem AWS, papéis de trabalho, precificação,

billing, arquitetura e uma introdução prática aos principais serviços (EC2, S3, VPC, IAM, CloudFront).

O learning path é composto por **11 treinamentos** (cursos digitais, labs e a avaliação final), que juntos somam cerca de **21h55min**

de conteúdo. 

O maior destaque é o curso **[AWS Cloud Practitioner Essentials](https://skillbuilder.aws/learn/94T2BEN85A/aws-cloud-practitioner-essentials/8D79F3AVR7?parentId=Y4YASRJEVX)** (12h45min), que sozinho já cobre boa parte do conteúdo da certificação AWS Certified Cloud Practitioner.

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo um treinamento, tiro um print/certificado de conclusão (quando disponível) e salvo na pasta `00-AWS-Cloud-Essentials/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

Ao final da trilha, faço o **Cloud Essentials Knowledge Badge Assessment** (nota mínima de 80%) para receber o badge digital emitido pela Credly.

## 📚 Resumo dos tópicos

**1. Job Roles in the Cloud** - Panorama de alto nível sobre os principais papéis de trabalho na nuvem AWS e como eles se comparam a papéis de TI on-premises, ajudando a entender a transição de funções para a nuvem.

**2. AWS Cloud Practitioner Essentials** - O curso mais completo da trilha: fundamentos dos serviços AWS, precificação, segurança, monitoramento e arquitetura. Base direta para a certificação AWS Certified Cloud Practitioner.

**3. Getting Started with Cloud Acquisition** - Como comprar AWS Cloud de forma eficaz, boas práticas de aquisição, benefícios de trabalhar com a AWS Partner Network (APN) e como superar desafios comuns de adoção da nuvem.

**4. AWS Billing and Cost Management** - Como usar o serviço de Billing and Cost Management da AWS, recursos para analisar e gerenciar os gastos na nuvem.

**5. AWS Foundations: Getting Started with the AWS Cloud Essentials** - Fundamentos da arquitetura AWS e visão geral das categorias de serviços: Compute, Storage, Database, Networking e Security.

**6. Introduction to Amazon EC2** - Lab prático de visão geral básica: como lançar, redimensionar, gerenciar e monitorar uma instância EC2.

**7. Introduction to Amazon Simple Storage Service (S3)** - Lab prático: criar um bucket, adicionar, visualizar, mover e excluir objetos e o próprio bucket via console AWS.

**8. Introduction to Amazon Virtual Private Cloud (VPC)** - Lab prático: criar uma VPC com o wizard, anexar um Internet Gateway, adicionar uma subnet e configurar o roteamento para permitir tráfego entre a subnet e a internet.

**9. Introduction to AWS Identity and Access Management (IAM)** - Lab prático: gerenciar acesso e permissões, adicionar usuários a grupos, gerenciar senhas, logar com usuários criados via IAM e observar o efeito das políticas de acesso.

**10. Introduction to Amazon CloudFront** - Lab prático: criar uma distribuição CloudFront para servir, via CDN, um arquivo de imagem público armazenado em um bucket S3.

**11. Cloud Essentials Knowledge Badge Assessment** - Avaliação final da trilha. Nota mínima de 80% para conquistar o badge (emitido pela Credly em 5-7 dias úteis).
