# 🎮 AWS Cloud Quest - Guia Prático & Documentação de Estudos

**Um repositório de estudos com as principais trilhas da AWS - pra entender a nuvem de verdade, evoluir na carreira e nunca parar de aprender.**

</div>

Bem-vindo ao repositório de documentação dos laboratórios do **AWS Cloud Quest**! 

O **AWS Cloud Quest** é um jogo de RPG (Role-Playing Game) interativo e prático desenvolvido pela
AWS no **AWS Skill Builder**. Nele, você assume o papel de um profissional de nuvem que resolve problemas
reais de uma cidade virtual usando serviços e arquiteturas reais da Amazon Web Services no próprio console
de gerenciamento da AWS.

---

## 🧭 Como Funciona a Dinâmica de Aprendizado?

Cada missão dentro do Cloud Quest é dividida em etapas bem estruturadas para garantir a fixação do conhecimento:

1. **Aprender (Learn):** Apresentação do cenário de negócio do cliente fictício e explicação detalhada dos conceitos teóricos envolvidos na solução.
2. **Praticar (Practice):** Um guia passo a passo estruturado dentro do ambiente de laboratório real do console da AWS para construir a solução do zero.
3. **Faça Você Mesmo (DIY - Do It Yourself):** Um desafio prático complementar sem instruções passo a passo detalhadas, onde você aplica o aprendizado para resolver uma variação do problema e valida a arquitetura de forma automática.
4. **Missões Secundárias e Recompensas:** Além das missões principais da história, o jogo inclui minigames e quizzes interativos sobre serviços da AWS para coletar petcoins, personalizar seu avatar, desbloquear veículos e evoluir a cidade virtual.

## 🎯 Trilhas Gratuitas Mapeadas neste Repositório

Embora a AWS ofereça diversas trilhas pagas (como *Solutions Architect*, *Security*, *DevOps*, etc.), este repositório é dedicado à documentação completa e gratuita das **duas principais trilhas fundamentais** disponíveis no plano free da AWS:

* 🟢 **AWS Cloud Quest: Cloud Practitioner** (~12 horas)
  * **Foco:** Fundamentos de computação (EC2), redes (VPC, Peering, Subnets), segurança (Security Groups), armazenamento (S3, EBS) e bancos de dados (RDS, DynamoDB).
  * 🔗 [Acessar no AWS Skill Builder](https://skillbuilder.aws/learn/FU5WCYVGKY/aws-cloud-quest-cloud-practitioner/JF9TKU68GT)

* 🤖 **AWS Cloud Quest: Generative AI Practitioner** (~10 horas)
  * **Foco:** Fundamentos de Inteligência Artificial Generativa, Modelos de Fundação (FMs), Amazon Bedrock, Prompt Engineering e casos de uso de IA na nuvem.
  * 🔗 [Acessar no AWS Skill Builder](https://skillbuilder.aws/learn/5YB3FCEE1H/aws-cloud-quest-generative-ai-practitioner/26A81MG83V)

## 📂 Estrutura das Missões Documentadas

Cada pasta/arquivo neste repositório representa uma missão e segue o padrão pedagógico:
* **Overview:** Problema de negócio simulado e arquitetura proposta.
* **Aprender:** Teoria e conceitos para a certificação AWS.
* **Praticar:** Guia com o passo a passo executado no console AWS.
* **DIY (Faça Você Mesmo):** Desafio final de validação resolvido.

Também tem as **Missões secundárias** documentadas:
- Pets: encontre pets -  🟨 Em andamento
- Diagramas
- Flashcards
- Veículos e mobilidade
