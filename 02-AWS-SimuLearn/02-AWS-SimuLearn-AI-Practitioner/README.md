#  AWS SimuLearn - AI Practitioner

</div>

Este repositório documenta minha jornada pelo [**AWS SimuLearn: AI Practitioner**](https://skillbuilder.aws/learning-plan/BFKGA5VM8H/aws-simulearn-ai-practitioner), um plano de aprendizagem que usa IA generativa pra simular cenários reais de negócio.

Em cada treinamento, você conversa com um cliente fictício (gerado por IA) pra entender um problema de negócio, propõe uma solução na AWS, e depois constrói e valida essa solução na prática, em um ambiente real do AWS Management Console. Um agente de IA avalia suas respostas na conversa, e o "Dr. Newton" (assistente de IA) ajuda quando você trava.

O learning path é composto por **10 treinamentos**, que juntos somam cerca de **10h** de conteúdo, cobrindo desde os fundamentos de computação em nuvem até IA generativa, modelos de fundação no Amazon Bedrock, guardrails de segurança, assistentes inteligentes e uso de IA com Amazon SageMaker e Amazon Q.

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo uma simulação, tiro um print/certificado de conclusão e salvo na pasta `AWS-SimuLearn-AI-Practitioner/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

## 📚 Resumo dos tópicos

**1. AWS SimuLearn: Cloud Computing Essentials** - Cenário: a equipe web quer melhorar a confiabilidade de uma página de condições de ondas para surf. Trabalha os conceitos essenciais de computação em nuvem através de uma solução prática.

**2. AWS SimuLearn: Cloud First Steps** - Cenário: uma equipe de estabilização de ilha quer aumentar a confiabilidade e disponibilidade do seu sistema atual. Primeiros passos práticos na nuvem AWS.

**3. AWS SimuLearn: Explore the Amazon Bedrock Playgrounds** - Cenário: a equipe de negócios da AnyCompany quer encontrar o melhor modelo de IA para sua experiência de chat de atendimento ao cliente, comparando modelos que suportam texto e imagem.

**4. AWS SimuLearn: Generate Code for a Webpage** - Cenário: um departamento de marketing quer uma forma mais ágil de gerenciar e atualizar conteúdo e código de um web server, usando IA generativa mesmo com pouca expertise técnica em AWS.

**5. AWS SimuLearn: Get Started with Generative AI** - Cenário: a AnyCompany Software quer capacitar sua equipe em técnicas de prompt engineering para IA generativa, acelerando o desenvolvimento de software.

**6. AWS SimuLearn: Secure Conversational AI with Guardrails** - Cenário: o departamento de RH da AnyCompany quer um assistente de IA conversacional que responda apenas de forma profissional e compatível com as políticas internas, protegendo dados confidenciais dos funcionários.

**7. AWS SimuLearn: Create an Enterprise Knowledge Assistant** - Cenário: o time de vendas não tem acesso rápido a dados históricos e atuais de vendas, gerando respostas inconsistentes. Eles querem um assistente confiável para consultar tendências de performance de produtos.

**8. AWS SimuLearn: Create an AI Smart Assistant** - Cenário: o departamento de RH recebe mais de 500 solicitações diárias sobre políticas, benefícios e procedimentos, e precisa de um assistente de IA disponível fora do horário comercial.

**9. AWS SimuLearn: Use AI Services with Amazon SageMaker** - Cenário: uma consultoria global processa mais de 10.000 comunicações e documentos multilíngues por dia com processos manuais caros e com alta taxa de erro, e precisa de uma solução automatizada de ponta a ponta.

**10. AWS SimuLearn: Build and Understand Code with Amazon Q** - Cenário: uma editora de conteúdo infantil quer criar um sistema automatizado de geração de histórias personalizadas com base em nomes de personagens, temas e cenários definidos pelo usuário.
