# 🗄️ Object Storage - Knowledge Badge Readiness Path

</div>

Este repositório documenta minha jornada para conquistar o **AWS Object Storage Knowledge Badge**, disponível no AWS Skill Builder.

O learning path é composto por **19 treinamentos** (cursos digitais, labs e a avaliação final), que juntos somam cerca de **20h20min** de conteúdo, cobrindo desde os fundamentos do Amazon S3 até segurança, auditoria, performance, custo, disaster recovery e replicação entre regiões.

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo um treinamento, tiro um print/certificado de conclusão (quando disponível) e salvo na pasta `AWS-Object-Storage/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

Ao final da trilha, faço o [Object Storage Knowledge Badge Assessment](https://skillbuilder.aws/learning-plan/BJEHDY31SM/object-storage--knowledge-badge-readiness-path-includes-labs/TMJC4UK375?_sa=search&_si=577733fc-f0d3-4a70-bfb8-918a7fc90473&_sq=4e8292f1-9ce3-415e-b318-9d124b5e2d28) (nota mínima de 80%) para receber o badge digital emitido pela Credly.

## 📚 Resumo dos tópicos

**1. AWS Storage Services - Portfolio Introduction** - Visão geral do portfólio de armazenamento da AWS (block, object e file storage), soluções híbridas, transferência e proteção de dados, e como escolher a solução certa para cada workload.

**2. AWS Object Storage Services Getting Started** - Introdução ao Amazon S3, suas storage classes (incluindo S3 Glacier) e as opções de automação de tiering entre classes.

**3. Amazon S3 Storage Classes Deep Dive** - Diferenças entre as storage classes do S3, dimensões de precificação de cada uma e como escolher a classe ideal para cada workload.

**4. Introduction to Amazon Simple Storage Service (S3)** - Lab prático: criar um bucket, adicionar, visualizar, mover e excluir objetos e o próprio bucket via console AWS.

**5. Lab - Create a Static Website with Amazon S3** - Lab prático de criação de um site estático hospedado em um bucket S3.

**6. Hosting WordPress Using Amazon S3** - Lab prático de hospedagem de um blog WordPress usando S3, incluindo criação e gerenciamento de um site estático.

**7. Enforcing Amazon S3 Security Policies** - Lab prático de boas práticas preventivas de segurança no S3: origem de acesso, permissões, criptografia em repouso e em trânsito, e tipo de criptografia exigido para compliance.

**8. Setting up Amazon S3 for Application Storage** - Lab prático de integração de uma aplicação com S3: acessar imagens armazenadas em um bucket, gerar novas imagens e criar URLs pré-assinadas (presigned URLs).

**9. Amazon Simple Storage Service (S3) - Troubleshooting** - Como coletar informações sobre o S3 para diagnosticar problemas comuns e abrir cases de suporte mais efetivos junto à AWS.

**10. Managing Access at Scale with Amazon S3 Access Points** - Lab prático de uso de S3 Access Points para simplificar o controle de acesso a objetos, com base em tags e VPCs específicas.

**11. Auditing Amazon Simple Storage Service (S3) Security** - Como auditar continuamente o acesso e as configurações do S3, usando recursos do próprio serviço e de outros serviços da AWS.

**12. Managing Amazon Simple Storage Service (S3)** - Ferramentas de gestão do S3 para organizar, automatizar e monitorar dados, além de acompanhar atividade, armazenamento e performance.

**13. Performing a Basic Audit of your AWS Environment** - Lab prático de auditoria básica de recursos AWS (EC2, VPC, IAM, Security Groups, CloudTrail, CloudWatch).

**14. Amazon Simple Storage Service (S3) Performance Optimization** - Técnicas para otimizar a performance de interações com objetos no S3, reduzindo downtime e melhorando a experiência do usuário.

**15. Amazon Simple Storage Service (S3) Cost Optimization** - Técnicas para reduzir custos no S3 sem sacrificar performance, e ferramentas para entender e prever a fatura.

**16. Securing and Protecting Your Data in Amazon S3** - Boas práticas de segurança do S3: bloqueio de acesso público, controles de acesso e criptografia de dados em repouso e em trânsito.

**17. Amazon Simple Storage Service (S3) Business Continuity and Disaster Recovery** - Como usar replicação de dados, versionamento e S3 Object Lock para atender planos de continuidade de negócio e recuperação de desastres.

**18. Implementing Multi-Region Backup with Amazon S3 Cross-Region Replication** - Lab prático de configuração de Cross-Region Replication entre buckets de origem e destino, incluindo versionamento e diferentes políticas de replicação.

**19. Object Storage Knowledge Badge Assessment** - Avaliação final da trilha. Nota mínima de 80% para conquistar o badge (emitido pela Credly em 5-7 dias úteis).
