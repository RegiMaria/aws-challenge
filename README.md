# 🚀 AWS Challenge

**Um repositório de estudos com as principais trilhas da AWS - pra entender a nuvem de verdade, evoluir na carreira e nunca parar de aprender.**

</div>

---

## 📌 O que é isso aqui?

O **AWS Challenge** é o meu registro público de estudo contínuo na AWS. A ideia nasceu de uma pergunta simples: *como transformar "eu quero aprender AWS" em um plano real, com progresso visível e resultado prático?*

Aqui eu documento, dia após dia, as principais trilhas de conhecimento (Knowledge Badge Readiness Paths) e badges do AWS Skill Builder e do AWS Educate, do básico ao avançado, com o objetivo de:

- 🧠 **Compreender a AWS de verdade**, não só decorar serviço por serviço, mas entender como eles se conectam.
- 📈 **Evoluir na carreira**, construindo uma base sólida que sustenta tanto certificações quanto o dia a dia como profissional de cloud.
- 🏆 **Conquistar oportunidades**, com badges e certificados verificáveis que comprovam o conhecimento adquirido.
- 🔁 **Estar sempre aprendendo**, mantendo um ritmo constante de estudo em vez de picos isolados.

> 📅 **A regra do desafio é simples: cada tópico de cada trilha = 1 dia de estudo.** Sem pular etapas, sem maratonar, constância antes de velocidade.

## 🧭 Como cada trilha é organizada

Dentro de cada pasta você encontra:
- Um `README.md` com o resumo de cada tópico/curso da trilha.
- Uma tabela de progresso (dia, data, tópico, descrição, certificado e link oficial da AWS).
- Os certificados/prints de conclusão de cada dia de estudo.

---

## 🎯 Por que público?

Porque aprender em público cria compromisso, e porque, se esse repositório ajudar mais alguém a organizar os próprios estudos de AWS, o desafio já valeu a pena em dobro. Sinta-se à vontade para usar essa estrutura como inspiração para o seu próprio desafio. 🙌
