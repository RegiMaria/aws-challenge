# ☁️ 00 AWS Knowledge Badge Path

</div>

Este repositório documenta minha jornada para conquistar as badges de AWS Knowledge.


As badges de AWS Knowledge focam no domínio prático e aprofundado de um serviço 
ou domínio específico (como Serverless, Networking Core, Compute, Object Storage, etc.).

Em vez de cobrar um escopo genérico de toda a nuvem AWS, cada plano de aprendizado 
(Learning Path) foca no ecossistema daquela tecnologia específica:

**O que é avaliado:* Conceitos fundamentais e intermediários, padrões de
arquitetura, segurança, observabilidade, precificação e integração do serviço focado.

**Como funciona a conquista:** Você conclui a trilha de aprendizado gratuita no 
AWS Skill Builder e passa em um teste final (Assessment) de múltipla escolha com 80% ou mais de acerto.

**Prática inclusa:* As trilhas incluem cursos digitais teóricos e demonstrações/laboratórios práticos (AWS Builder Labs).
