# Serverless - Knowledge 

Este repositório documenta a minha jornada de estudos na trilha **Serverless Knowledge Badge Readiness Path** 
da AWS. O objetivo é adquirir conhecimentos profundos sobre arquiteturas serverless,
computação orientada a eventos, segurança, observabilidade e boas práticas com serviços da AWS.

---

## 📊 Visão Geral da Trilha

- **Nome da Trilha:** Serverless Knowledge Badge Readiness Path (includes Labs)
- **Duração Total:** 14 horas e 15 minutos
- **Avaliação:** 4.8 / 5.0 (baseado em 47 avaliações)
- **Meta:** Concluir todos os módulos e obter o **Serverless Knowledge Badge** emitido pela Credly.

---

## 📋 Trilha de Cursos e Laboratórios (Checklist)

Aqui estão listados todos os módulos que compõem este plano de aprendizado:

- [ ] [**1. Getting into the Serverless Mindset**](https://skillbuilder.aws/learn/6V6HTC5W5D/getting-into-the-serverless-mindset/4EF5792A2K?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Fundamental | **Duração:** 30m
  - **Descrição:** Introdução aos conceitos-chave de serverless para planejar arquiteturas e aplicações orientadas a eventos.

- [ ] [**2. AWS Lambda Foundations**](https://skillbuilder.aws/learn/XHRS91KKK6/aws-lambda-foundations/R85JRN3APC?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Fundamental | **Duração:** 2h
  - **Descrição:** Fundamentos do AWS Lambda, escrita, configuração, testes, monitoramento e solução de problemas. *(Concluído)*

- [ ] [**3. Introduction to AWS Lambda**](https://skillbuilder.aws/learn/G3BEYRFNPS/introduction-to-aws-lambda/5PSQXY58Y7?parentId=W62PSCYRZF)
  - **Tipo:** Laboratório Builder da AWS | **Nível:** Fundamental | **Duração:** 45m
  - **Descrição:** Primeiros passos práticos para criar e implantar uma função Lambda em um ambiente orientado a eventos.

- [ ] [**4. Designing Event-Driven Architectures**](https://skillbuilder.aws/learn/9M9FHG925K/designing-eventdriven-architectures/A3Y38BXWC6?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Intermediário | **Duração:** 2h
  - **Descrição:** Padrões e serviços da AWS para desacoplar estados, uso de Amazon SQS, AWS Step Functions e API Gateway.

- [ ] [**5. Scaling Serverless Architectures**](https://skillbuilder.aws/learn/Z5UZYF3RKH/scaling-serverless-architectures/A7FYXA9TNE?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Intermediário | **Duração:** 1h 30m
  - **Descrição:** Escolha de serviços para escala, otimização de velocidade de funções Lambda, opções de armazenamento e estratégias de teste.

- [ ] [**6. Security and Observability for Serverless Applications**](https://skillbuilder.aws/learn/7NWTHTHDFD/security-and-observability-for-serverless-applications/CQBAH1XKR4?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Intermediário | **Duração:** 1h 30m
  - **Descrição:** Boas práticas de segurança, monitoramento e auditoria usando AWS CloudTrail, Amazon CloudWatch, AWS Config e AWS X-Ray.

- [ ] [**7. Deploying Serverless Applications**](https://skillbuilder.aws/learn/M531VCW415/deploying-serverless-applications/SMY21G7FYZ?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Intermediário | **Duração:** 1h 30m
  - **Descrição:** Pipelines automatizados de CI/CD para aplicações serverless utilizando ferramentas da AWS e o AWS Serverless Application Model (AWS SAM).

- [ ] [**8. Amazon API Gateway for Serverless Applications**](https://skillbuilder.aws/learn/GQA6FHWPJD/amazon-api-gateway-for-serverless-applications/JVRZ3PSW4H?parentId=W62PSCYRZF)
  - **Tipo:** Curso Digital | **Nível:** Fundamental | **Duração:** 2h
  - **Descrição:** Criação e implantação de APIs, gerenciamento de acesso e integração com o AWS Lambda.

- [ ] [**9. Troubleshooting API Gateway with Lambda Proxy Integration**](https://skillbuilder.aws/learn/RNFQU4XGGZ/troubleshooting-api-gateway-with-lambda-proxy-integration/WTSRTDN7AU?parentId=W62PSCYRZF)
  - **Tipo:** Laboratório Builder da AWS | **Nível:** Intermediário | **Duração:** 1h
  - **Descrição:** Prática de resolução de problemas (como o erro 500 Internal Server Error) em integrações de API Gateway com Lambda Proxy.

- [ ] [**10. Serverless Knowledge Badge Assessment**](https://skillbuilder.aws/learn/736QB43CDN/serverless-knowledge-badge-assessment/FNZFSSTF94?parentId=W62PSCYRZF)
  - **Tipo:** Avaliação | **Nível:** Intermediário | **Duração:** 1h 30m
  - **Descrição:** Avaliação final para validar a compreensão da trilha e conquistar o badge oficial (requer nota mínima de 80%).
