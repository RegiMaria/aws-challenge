## Sobre o Curso

O AWS Lambda Foundations é um curso digital de nível fundamental com duração de 2 horas,
focado na construção de aplicações serverless na Amazon Web Services. A formação aborda 
desde os conceitos internos de funcionamento do AWS Lambda até práticas de escrita de código, 
configuração de permissões de segurança, estratégias de implantação, testes, monitoramento e
solução de problemas (troubleshooting).

- Faz parte do[ Serverless - Knowledge Badge Readiness Path (includes Labs)](https://skillbuilder.aws/learning-plan/VD4SU58H3W/serverless--knowledge-badge-readiness-path-includes-labs/W62PSCYRZF)

Este repositório contém anotações, resumos, códigos práticos e documentação gerada durante a
execução da trilha.


## Objetivos de Aprendizagem
[x] Compreender o funcionamento interno e o ciclo de vida de uma função AWS Lambda.

[x] Configurar permissões e segurança utilizando o AWS Identity and Access Management (IAM).

[x] Aplicar as melhores práticas na escrita e estruturação do código da função (handler).

[x] Configurar parâmetros essenciais como memória, timeouts e variáveis de ambiente.

[x] Realizar implantação (deploy) e testes de aplicações serverless usando o AWS SAM.

[x] Monitorar métricas, analisar logs e depurar erros em produção.


## Serviços e Ferramentas AWS
AWS Lambda: Serviço de computação serverless orientado a eventos.

AWS Serverless Application Model (SAM): Framework para definição e implantação de infraestrutura como código (IaC) serverless.

AWS IAM (Identity and Access Management): Gerenciamento de papéis (roles) e políticas de segurança para execução das funções.

Amazon CloudWatch: Monitoramento de métricas, coleta de logs e alarmes.
