#  AWS SimuLearn - Cloud Practitioner

</div>

Este repositório documenta minha jornada pelo **AWS SimuLearn: Cloud Practitioner**, um plano de aprendizagem que usa IA generativa pra simular cenários reais de negócio.

Em cada treinamento, você conversa com um cliente fictício (gerado por IA) pra entender um problema de negócio, propõe uma solução na AWS, e depois constrói e valida essa solução na prática, em um ambiente real do AWS Management Console. Um agente de IA avalia suas respostas na conversa, e o "Dr. Newton" (assistente de IA) ajuda quando você trava.

O learning path é composto por **12 treinamentos**, que juntos somam cerca de **12h** de conteúdo, cobrindo desde os fundamentos de computação em nuvem até bancos de dados NoSQL, segurança, redes, alta disponibilidade e auto-scaling.

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo uma simulação, tiro um print/certificado de conclusão e salvo na pasta `AWS-SimuLearn-Cloud-Practitioner/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

## 📚 Resumo dos tópicos

**1. AWS SimuLearn: Cloud Computing Essentials** - Cenário: a equipe web quer melhorar a confiabilidade de uma página de condições de ondas para surf. Trabalha os conceitos essenciais de computação em nuvem através de uma solução prática.

**2. AWS SimuLearn: Cloud First Steps** - Cenário: uma equipe de estabilização de ilha quer aumentar a confiabilidade e disponibilidade do seu sistema atual. Primeiros passos práticos na nuvem AWS.

**3. AWS SimuLearn: Computing Solutions** - Cenário: uma escola quer migrar seu sistema de agendamento de aulas (rodando em uma instância EC2) para uma opção com mais poder de processamento e memória.

**4. AWS SimuLearn: First NoSQL Database** - Cenário: uma empresa de streaming quer coletar dados de comportamento dos espectadores em um banco de dados de alta performance e escalável.

**5. AWS SimuLearn: Networking Concepts** - Cenário: um banco quer estabelecer uma arquitetura de rede que controle com segurança a comunicação entre seus recursos internos e a internet.

**6. AWS SimuLearn: Cloud Economics** - Cenário: uma loja de artigos de surf quer uma estimativa de custo para uma arquitetura de nuvem escalável que sustente sua loja online.

**7. AWS SimuLearn: File Systems in the Cloud** - Cenário: uma agência de modelos (pet) quer uma forma de compartilhar arquivos entre suas filiais sem gerenciar infraestrutura física de armazenamento.

**8. AWS SimuLearn: Databases in Practice** - Cenário: uma seguradora quer que seus administradores de banco de dados gastem menos tempo com tarefas operacionais (como patching), além de melhorar a disponibilidade e eficiência do banco.

**9. AWS SimuLearn: Core Security Concepts** - Cenário: uma bolsa de valores quer restringir o acesso de engenheiros de suporte apenas às ações necessárias para suas funções, reforçando os controles de segurança.

**10. AWS SimuLearn: Auto-Healing and Scaling Applications** - Cenário: um cyber café/gaming café quer implementar servidores com auto-recuperação (auto-healing) e restringir usuários a uma capacidade de provisionamento específica.

**11. AWS SimuLearn: Highly Available Web Applications** - Cenário: uma agência de viagens quer garantir que sua aplicação web continue disponível para os clientes mesmo se alguns componentes do sistema falharem.

**12. AWS SimuLearn: Connecting VPCs** - Cenário: o time de Marketing quer manter ambientes de rede separados por departamento, garantindo que ainda consigam se comunicar entre si.
