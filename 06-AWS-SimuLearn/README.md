# AWS SimuLearn - Anotações e Progresso

Repositório com minhas anotações, resumos e materiais dos desafios do **AWS SimuLearn**, parte do AWS Skill Builder.

## O que é o AWS SimuLearn?

O AWS SimuLearn é uma experiência de aprendizado imersiva que combina **simulações de clientes com IA generativa** e **construção prática em ambientes reais da AWS**. Em cada plano de aprendizagem, você:

1. **Conversa com clientes virtuais** para levantar requisitos de negócio
2. **Desenvolve propostas de arquitetura** com base nesses requisitos
3. **Constrói a solução** no Console da AWS (ambiente real)
4. **Valida o trabalho** através de uma avaliação DIY automatizada

Ao concluir **todas as atividades de um plano de aprendizagem**, você ganha um **badge oficial da AWS** (emitido via Credly), que pode ser compartilhado no LinkedIn e com empregadores como prova verificável de habilidades práticas em nuvem.

Existem **12 planos de aprendizagem** no total. Dois são gratuitos (Cloud Practitioner e AI Practitioner); os outros 10 exigem assinatura do AWS Skill Builder.

## Estrutura do repositório

Cada plano de aprendizagem tem sua própria pasta na raiz, numerada na ordem em que fui cursando:

```
aws-simulearn-notes/
├── README.md                          ← este arquivo (índice geral)
├── 00-AWS-Cloud-Essentials/
│   ├── README.md                      ← resumo do módulo
│   └── notas.md
├── 01-AWS-Security-Champion/
│   ├── README.md
│   └── notas.md
...
```

Dentro de cada pasta, o `README.md` local traz um resumo do plano, principais conceitos aprendidos e, quando aplicável, evidências (screenshots, comandos) das atividades DIY.
