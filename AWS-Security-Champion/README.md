Este repositório documenta minha jornada para conquistar o [AWS Security Champion Knowledge Badge, disponível no AWS Skill Builder](https://skillbuilder.aws/learning-plan/31WSD993AF/aws-security-champion--knowledge-badge-readiness-path/QGY41BBUDQ?_sa=search&_si=afabe2eb-e11f-49db-85dd-cac52e20d6a6&_sq=70681a4f-6f4c-4956-8a57-7e03dfc3c51d).

O learning path é composto por **17 treinamentos** (cursos digitais, labs e um SimuLearn), que juntos somam cerca de **26h15min** de conteúdo. A ideia deste desafio é simples:

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo um treinamento, tiro um print/certificado de conclusão (quando disponível) e salvo na pasta `AWS-Security-Champion/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

Ao final da trilha, faço o **AWS Security Champion Badge Assessment** (nota mínima de 80%) para receber o badge digital emitido pela Credly.

---

## 🌻 Resumo dos tópicos

**1. AWS Security Fundamentals** - Conceitos fundamentais de segurança na nuvem AWS: controle de acesso, criptografia de dados e como proteger o acesso de rede à sua infraestrutura, além do modelo de responsabilidade em segurança.

**2. AWS Shared Responsibility Model** - Introdução ao Modelo de Responsabilidade Compartilhada: o que é responsabilidade da AWS e o que é responsabilidade do cliente, dos componentes físicos até os dados do usuário.

**3. Introduction to AWS Identity and Access Management (IAM)** - Fundamentos de autenticação e autorização com IAM, políticas, roles e um demo prático de criação de grupo/usuário IAM.

**4. AWS IAM - Troubleshooting** - Como monitorar, diagnosticar e resolver problemas comuns de IAM, incluindo como abrir um case de suporte na AWS com informações úteis.

**5. Lab - Troubleshooting - IAM Access Issues** - Lab prático (break/fix) sobre assumir roles do IAM via console, aplicando o princípio do menor privilégio.

**6. Introduction to AWS Key Management Service** - Lab prático de introdução ao KMS: criação de chaves, permissões de uso/gestão, criptografia de dados e monitoramento de acesso.

**7. Threat Modeling for Builders Workshop** - Workshop sobre modelagem de ameaças (threat modeling): por que fazer, ferramentas e técnicas para modelar sistemas, identificar ameaças e escolher mitigações.

**8. Security Governance at Scale – Technical (Digital)** - Como automatizar a governança de nuvem em escala (gestão de contas, orçamento, compliance), aplicando controles preventivos e detectivos.

**9. Performing a Basic Audit of your AWS Environment** - Lab prático de auditoria básica de recursos AWS (EC2, VPC, IAM, Security Groups, CloudTrail, CloudWatch).

**10. AWS Security Best Practices: Monitoring and Alerting** - Boas práticas de monitoramento e alertas: logging de rede, usuários e tráfego de API, além de auditoria do ambiente AWS.

**11. AWS Security Best Practices: Network Infrastructure** - Boas práticas de segurança voltadas à infraestrutura de rede na AWS.

**12. Protect Your Web-facing Workloads with AWS Security Services** - Como planejar e implementar serviços de segurança AWS para proteger workloads expostos à web.

**13. Implementing and Controlling Network Traffic on AWS** - Lab prático usando subnets públicas/privadas, security groups e ACLs para criar uma infraestrutura de rede com três zonas de segurança na VPC, monitorada via VPC Flow Logs.

**14. AWS Security Incident Response Overview** - Introdução ao workflow de resposta a incidentes de segurança e como usar serviços AWS em cada fase da investigação.

**15. AWS Security Incident Response - Compromised IAM Credentials Use Case** - Estudo de caso guiado: investigação de um incidente envolvendo credenciais IAM comprometidas.

**16. AWS SimuLearn: Core Security Concepts** - Cenário simulado com IA generativa, onde você desenha e constrói uma solução de segurança (restrição de acesso de suporte) em um ambiente real do console AWS.

**17. AWS Security Champion Badge Assessment** - Avaliação final da trilha. Nota mínima de 80% para conquistar o badge (emitido pela Credly em 5-7 dias úteis).
