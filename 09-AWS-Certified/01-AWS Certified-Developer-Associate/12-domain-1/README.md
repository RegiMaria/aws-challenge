## Visão Geral do Curso

Neste curso, você revisará os tópicos principais do **Domínio
1 (Desenvolvimento com Serviços AWS)**, analisando como eles se alinham aos serviços da AWS
e às áreas específicas de estudo cobradas no exame DVA-C02. 

O conteúdo é estruturado em vídeo-aulas ministradas por instrutores especialistas da AWS,
que abordam as melhores práticas de arquitetura, integração de código e estratégias de
desenvolvimento na nuvem.

---

## Conteúdo e Tópicos Cobertos (Domínio 1)

O Domínio 1 representa a maior porcentagem de peso na prova de Developer Associate.
Os principais tópicos revisados incluem:

* **Integração de Código & SDKs:** Uso do AWS SDK, AWS CLI e APIs para interagir programaticamente com serviços AWS.
* **Serverless Development:** Criação e gerenciamento de aplicações usando **AWS Lambda** e **Amazon API Gateway**.
* **Persistência de Dados & NoSQL:** Modelagem de dados, índices (LSI/GSI) e operações no **Amazon DynamoDB**.
* **Mensageria & Event-Driven:** Desacoplamento de aplicações com **Amazon SQS**, **Amazon SNS** e **Amazon EventBridge**.
* **Gerenciamento de Estado:** Orquestração de fluxos e microserviços com **AWS Step Functions**.

4. **Avaliar a Preparação:** Realizar o simulado oficial da AWS.
