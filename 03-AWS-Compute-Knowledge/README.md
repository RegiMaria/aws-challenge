# ⚙️ Compute - Knowledge Badge Readiness Path

</div>

Este repositório documenta minha jornada para conquistar o **AWS Compute Knowledge Badge**, disponível no AWS Skill Builder.

O learning path é composto por **14 treinamentos** (todos cursos digitais), que juntos somam cerca de **16h20min** de conteúdo, cobrindo desde os fundamentos de EC2, Lambda e containers até otimização de custo, observabilidade e confidential computing.

> 📅 **Cada tópico da trilha = 1 dia de estudo.**

A cada dia eu completo um treinamento, tiro um print/certificado de conclusão (quando disponível) e salvo na pasta `AWS-Compute/` com o padrão de nome `day-XX-nome-do-topico.png`. Todo o progresso fica registrado na tabela lá embaixo.

Ao final da trilha, faço o **Compute Knowledge Badge Assessment** (nota mínima de 80%) para receber o badge digital emitido pela Credly.

🔗 Trilha completa no Skill Builder: [Compute - Knowledge Badge Readiness Path](https://skillbuilder.aws/learning-plan/AE98BDMWT1/compute--knowledge-badge-readiness-path/6BA8EVB278)

## 📚 Resumo dos tópicos

**1. AWS Compute Services Overview** - Visão geral das três principais categorias de compute na AWS: Amazon EC2, Containers (ECS/EKS) e Serverless (Lambda). Ajuda a entender como escolher a melhor opção de compute para cada workload.

**2. Amazon EC2 Basics** - Explora as diferentes famílias de instâncias EC2, os workloads que cada uma atende, e como escolher o tipo de instância ideal considerando custo e performance.

**3. AWS Graviton Processors Fundamentals** - Conceitos técnicos e benefícios dos processadores Graviton (custom-designed pela AWS), voltados a melhor custo-benefício em workloads na nuvem.

**4. AWS AI Chips - Trainium and Inferentia Fundamentals** - Chips de IA desenvolvidos pela AWS para tornar workloads de IA mais eficientes e baratos, com instâncias EC2 dedicadas.

**5. AWS Nitro System Deep Dive** - Arquitetura do Nitro System (hardware dedicado + hypervisor leve) que sustenta segurança, performance e flexibilidade das instâncias EC2.

**6. Build with Amazon EC2** - Componentes de uma instância EC2 e como configurar, lançar e acessar instâncias de forma segura, resiliente e econômica.

**7. AWS Lambda Foundations** - Fundamentos do AWS Lambda (compute serverless orientado a eventos): como escrever, configurar, implantar, testar, monitorar e depurar funções Lambda.

**8. Compute Cost Optimization Services** - Modelos de compra do EC2 (On-Demand, Reserved, Spot), right-sizing, escolha de processador (incluindo Graviton) e reservas de capacidade sob demanda.

**9. Introduction to Capacity Manager for Amazon EC2** - Como usar o Capacity Manager para agregar, visualizar e gerenciar a capacidade EC2/Spot/reservas entre regiões e contas, reduzindo custos.

**10. Amazon EC2 Observability, Monitoring, and Troubleshooting** - Técnicas de observabilidade e monitoramento para garantir a saúde das instâncias EC2 e ferramentas para troubleshooting de problemas comuns.

**11. Right Size Your Amazon EC2 Workload** - Como identificar over/under-provisioning e ajustar (rightsize) as instâncias EC2 para otimizar custo e performance.

**12. Innovations in Amazon EC2** - História e evolução do EC2, a ampla gama de instâncias disponíveis hoje e introdução ao Nitro System.

**13. Confidential Computing with AWS Compute** - Como proteger dados durante o processamento usando Nitro System e Nitro Enclaves, com casos de uso como ML, colaboração multi-party e blockchain.

**14. Compute Knowledge Badge Assessment** - Avaliação final da trilha. Nota mínima de 80% para conquistar o badge (emitido pela Credly em 5-7 dias úteis).
